# مدل آواتار (اختیاری)

اگر یک مدل انسان سه‌بعدی قانونی با فرمت GLB دارید که Morph Target دهان/فک
(مثل `mouthOpen`، `jawOpen`، `viseme_aa`) دارد، فایل را دقیقاً با این نام
اینجا بگذارید:

```
avatar.glb
```

دستیار به‌صورت خودکار آن را لود می‌کند و لیپ‌سینک دامنه‌ای روی مورف‌های
دهان انجام می‌شود؛ اگر فایل نباشد، آواتار رویه‌ای داخلی استفاده می‌شود.

قبل از افزودن هر مدل، منبع و لایسنس آن را در `docs/assistant/ASSET_LICENSES.md`
ثبت کنید. مدلی بدون لایسنس روشن وارد پروژه نکنید.
