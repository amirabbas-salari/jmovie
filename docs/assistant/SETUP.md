# راه‌اندازی دستیار صوتی زنده (ابری و رایگان)

بدون هیچ کلیدی، دستیار در **حالت مرورگر** (رایگان، بدون LLM) کار می‌کند. برای گفتگوی صوتی زنده‌ی واقعی، سه بخش زیر لازم است — همه ابری و رایگان‌اند و هیچ‌چیز روی لوکال اجرا نمی‌شود.

## ۱) LiveKit (پلن رایگان Build یا سلف‌هاست)

1. در https://cloud.livekit.io ثبت‌نام کنید و یک Project بسازید.
2. از Settings → API Keys یک کلید بسازید.
3. در بک‌اند (`.env` جنگو) ست کنید:

```
LIVEKIT_URL=wss://<your-project>.livekit.cloud
LIVEKIT_API_KEY=...
LIVEKIT_API_SECRET=...
```

پلن Build رایگان است (بدون کارت) و سهمیه‌اش برای پروتوتایپ کافی است.

## ۲) گفتار ابری: Groq (پلن Free، بدون کارت)

1. در https://console.groq.com ثبت‌نام کنید.
2. از بخش API Keys یک کلید بسازید (`gsk_...`).
3. فقط روی سرور ایجنت صوتی ست کنید:

```
SPEECH_PROVIDER=groq
GROQ_API_KEY=gsk_...
```

ایجنت به‌صورت پیش‌فرض از همین‌ها استفاده می‌کند: شنیدن با `whisper-large-v3-turbo` و صحبت‌کردن با `canopylabs/orpheus-v1-english` (صدای `autumn`). چون صدای خروجی انگلیسی است، مکالمه هم انگلیسی انجام می‌شود؛ Whisper فارسی را هم می‌فهمد ولی پاسخ صوتی انگلیسی است. سقف پلن رایگان (مثلاً حدود ۱۰۰ درخواست TTS در روز) برای پروتوتایپ مناسب است، نه ترافیک بالا.

> گزینه‌ی فارسی/لوکال: اگر بعداً گفتار فارسی بدون ابر خواستید، `SPEECH_PROVIDER=local` با سرور Speaches و Piper فارسی در `voice_agent/README.md` مستند شده است.

## ۳) LLM (OpenAI-compatible)

پیش‌فرض همان OpenRouter سایت است:

```
OPENROUTER_API_KEY=...
OPENROUTER_MODEL=openai/gpt-4o-mini
```

سکرت مشترک جنگو و ایجنت را هم بسازید (رشته‌ی تصادفی بلند، مثل خروجی `openssl rand -hex 32`) و در **هر دو** ست کنید:

```
ASSISTANT_INTERNAL_SECRET=...
```

## ۴) اجرا

```bash
# بک‌اند (مثل همیشه)
cd backend/jmovie && python manage.py runserver

# ایجنت صوتی (ترمینال جدا)
cd voice_agent
pip install -r requirements.txt
python agent.py dev      # توسعه — یا start برای production
```

بعد در سایت روی «دستیار سینمایی» بزنید؛ اگر توکن صادر شود و ایجنت به اتاق وصل باشد، دکمه‌ی «شروع مکالمه‌ی صوتی» مکالمه را آغاز می‌کند. میکروفون فقط بعد از کلیک کاربر و اجازه‌ی مرورگر روشن می‌شود.

## عیب‌یابی سریع

- **همیشه حالت مرورگر می‌آید**: `GET /ai/assistant/status/` را ببینید؛ `livekit_configured` یعنی هر سه متغیر LiveKit در env جنگوست.
- **توکن می‌آید ولی صدایی نیست**: ایجنت در حال اجرا نیست یا `GROQ_API_KEY` روی سرور ایجنت ست نشده است (ایجنت هنگام بالا آمدن، متغیرهای ناقص را با پیام روشن اعلام می‌کند). سقف روزانه‌ی پلن رایگان Groq را هم بررسی کنید.
- **خطای 403 روی ابزارها**: `ASSISTANT_INTERNAL_SECRET` در جنگو و ایجنت یکی نیست.
